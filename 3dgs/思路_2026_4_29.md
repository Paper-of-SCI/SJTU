# 水下少视角 3DGS 思路整理

## 0. 创新点速查表

| 排名 | 创新点 | 能不能主打 | 一句话说明 | 论文里怎么写 | 区别于已有方法 |
|---|---|---|---|---|---|
| 1 | **语义偏置 cross-attention 证据路由** | **主创新** | 语义不是拼到 token 里，而是变成 **每个 3D query 和每个 patch 的 pair-wise bias \(b_{ij}\)**，加到 \(q_i k_j^\top\) score 上 | Semantic-biased pair-wise evidence routing for sparse-view underwater Gaussian reconstruction | 不同于 SWAGSplatting 给 Gaussian 加 semantic feature / semantic loss；也不同于 TextSplat 做多源 semantic feature fusion |
| 2 | **几何 / 介质双分支 semantic bias** | **主创新** | geometry branch 和 medium branch 使用不同 bias，分别路由真实表面证据和水体介质证据 | Object-medium disentangled semantic bias for Gaussian and medium prediction | 不是统一语义引导，而是按任务把物体表面证据和水体介质证据分流 |
| 3 | **Occupancy-decoupled sub-voxel Gaussian placement** | **主创新之一** | \(p_i\) 判断哪里有真实表面，\(\alpha_i\) 表示透明度，\(\Delta \mathbf{x}_i\) 修正 anchor 内位置 | Occupancy-decoupled sub-voxel Gaussian placement | 不靠 alpha 硬兜底，不是每 voxel 暴力撒 Gaussian，减少水雾被建成 floaters |
| 4 | **Spatially-varying medium field** | **辅助创新，不能单独主打** | 每个空间位置预测 \(\beta_d(\mathbf{x}), \beta_b(\mathbf{x}), B_\infty(\mathbf{x})\)，解释局部水体衰减和散射 | Spatially-varying underwater medium field coupled with semantic evidence routing | 单独做 \(\beta(\mathbf{x})\) 已有相近工作；必须和 semantic bias、occupancy 解耦绑定 |
| 5 | **Path-integrated medium-aware alpha compositing** | **辅助创新 / 强化模块** | 每个 Gaussian 的颜色先经过相机到它之间整段水路修正，再进入 3DGS alpha compositing | Path-integrated medium-aware Gaussian compositing | 比只查 Gaussian 中心点 medium 参数更物理，主要提升跨视角颜色一致性 |

最推荐的 contribution 顺序：

```text
1. Semantic-biased pair-wise cross-attention evidence routing
2. Object-medium disentangled dual-branch Gaussian refinement
3. Occupancy-decoupled sub-voxel Gaussian placement
4. Spatially-varying medium field with path-integrated rendering
```

不要单独主打：

```text
ViT 提 patch token
语义分割
semantic-guided 3DGS
medium-aware rendering
MLP 预测 Gaussian
triplane / voxel feature generator
```

这些只能作为组件，不是核心创新。

## 1. 一句话主线

本文不是简单做：

```text
水下 3DGS + 语义分割 + 水下渲染公式
```

而是针对水下少视角重建中最核心的混淆问题：

```text
真实物体表面证据
水体衰减 / 散射证据
背景雾化证据
少视角导致的不确定几何证据
```

提出一个少视角水下 Gaussian refinement 框架，让每个 3D Gaussian / sparse anchor 在修正位置、opacity、颜色和水体参数之前，通过语义偏置的 cross-attention 从多视角图像 patch 中选择正确证据。

术语边界：

```text
如果模型在多场景数据集上训练，测试新场景时直接前馈生成 Gaussian，
才可以严格叫 generalizable / 通用 3DGS。

如果输入依赖当前场景的 SfM sparse points / 已有 Gaussian 初始化，
就应写成 sparse-view underwater Gaussian refinement，
不要写成通用生成框架。
```

## 2. 核心方法公式总表

| 序号 | 公式 | 对应模块 | 论文里讲什么 |
|---|---|---|---|
| 1 | \(s_j=[p_{obj},p_{water},p_{seabed},p_{bg}]\) | patch-level soft semantics | patch 不硬分成一个类，而是保留类别概率 |
| 2 | \(H(s_j)=-\sum_c s_{j,c}\log s_{j,c}\) | semantic uncertainty | 混合 patch / 边界 patch 的不确定性 |
| 3 | \(q_i=\mathrm{MLP}_q([\gamma(\mathbf{x}_i),f_i])\) | 3D Gaussian query | query 来自 3D anchor 位置编码和多视角投影特征 |
| 4 | \(A_{ij}=q_i k_j^\top/\sqrt{d}+b_{ij}\) | pair-wise semantic-biased attention | \(b_{ij}\) 是每个 3D query 和每个 patch 的关系 bias |
| 5 | \(r_{ij}=\|\Pi(\mathbf{x}_i)-\mathbf{u}_j\|_2\) | query-patch 几何关系 | patch \(j\) 离 query \(i\) 的投影有多近 |
| 6 | \(b_{ij}^{geo}=\mathrm{MLP}_{geo}([s_j,H(s_j),\gamma(r_{ij}),m_{ij},\delta_{ij}])\) | geometry bias | 决定 3D 点 \(i\) 是否应该关注 patch \(j\) 的真实表面证据 |
| 7 | \(b_{ij}^{med}=\mathrm{MLP}_{med}([s_j,H(s_j),\gamma(r_{ij}),m_{ij},\delta_{ij}])\) | medium bias | 决定 3D 点 \(i\) 是否应该关注 patch \(j\) 的水体介质证据 |
| 8 | \(h_i^{geo}=\sum_j\operatorname{softmax}_j(A_{ij}^{geo})v_j\) | geometry feature aggregation | geometry 分支聚合真实表面证据 |
| 9 | \(h_i^{med}=\sum_j\operatorname{softmax}_j(A_{ij}^{med})v_j\) | medium feature aggregation | medium 分支聚合水体证据 |
| 10 | \(p_i=\sigma(\mathrm{MLP}_{occ}(h_i^{geo}))\) | occupancy head | 判断 anchor 附近有没有真实表面 |
| 11 | \(\Delta\mathbf{x}_i=\tanh(\mathrm{MLP}_{pos}(h_i^{geo}))\cdot r\) | sub-voxel offset | 修正 Gaussian 位置 |
| 12 | \(\mu_i=\mathbf{x}_i+\Delta\mathbf{x}_i\) | Gaussian center | 最终 Gaussian 中心 |
| 13 | \(\alpha_i^{final}=p_i\cdot\sigma(\alpha_i)\) | opacity decoupling | 占据和透明度解耦 |
| 14 | \((\beta_d(\mathbf{x}_i),\beta_b(\mathbf{x}_i),B_\infty(\mathbf{x}_i))=\mathrm{MLP}_{medium}([h_i^{med},\gamma(\mathbf{x}_i)])\) | medium field | 预测局部水体衰减、散射和背景水色 |
| 15 | \(A_i=\exp(-\int_0^{d_i}\beta_d(\mathbf{x}(t))\,dt)\) | path attenuation | 相机到 Gaussian 的路径衰减 |
| 16 | \(\tilde c_i=c_iA_i+S_i\) | underwater color | Gaussian 颜色经过水体修正 |
| 17 | \(C=\sum_iT_i\alpha_i^{final}\tilde c_i\) | rendering | 用 3DGS alpha compositing 合成最终颜色 |

## 3. 语义偏置 cross-attention：必须是 pair-wise bias

### 3.1 为什么不能只做 patch 全局 bias

错误的简化写法是：

$$
b_j=\mathrm{MLP}(s_j)
$$

这个写法的问题是：

```text
同一个 patch j 对所有 3D query i 都得到同一个 bias。
```

这只能表示：

```text
patch j 总体重要 / 不重要。
```

但真正需要的是：

```text
patch j 对当前 3D 点 i 是否重要。
```

例如：

```text
q1 投影到左边珊瑚附近；
q2 投影到右边石头附近；
patch j 是左边珊瑚 patch。
```

那么应该有：

$$
b_{1j}^{geo} \text{ 大}
$$

$$
b_{2j}^{geo} \text{ 小}
$$

如果只用 \(b_j=\mathrm{MLP}(s_j)\)，那 \(q1\) 和 \(q2\) 对同一个 patch 得到同样 bias，这是不对的。

所以 semantic bias 必须是：

```text
每个 3D query i 和每个 image patch j 一个 pair-wise bias b_ij。
```

---

### 3.2 正确的 attention 形式

对 geometry / occupancy branch：

$$
A_{ij}^{geo}
=
\frac{q_i^{geo}k_j^\top}{\sqrt{d}}
+
b_{ij}^{geo}
$$

对 medium branch：

$$
A_{ij}^{med}
=
\frac{q_i^{med}k_j^\top}{\sqrt{d}}
+
b_{ij}^{med}
$$

其中 \(b_{ij}\) 不是 patch 自己的分数，而是：

```text
3D query i 和 patch j 的关系分数。
```

---

### 3.3 pair-wise bias 输入应该包含什么

对第 \(i\) 个 3D query 和第 \(j\) 个 patch：

$$
b_{ij}^{geo}
=
\mathrm{MLP}_{geo}
(
\phi_{ij}^{geo}
)
$$

$$
b_{ij}^{med}
=
\mathrm{MLP}_{med}
(
\phi_{ij}^{med}
)
$$

其中推荐：

$$
\phi_{ij}
=
[
s_j,\ H(s_j),\ \gamma(r_{ij}),\ m_{ij},\ \delta_{ij}
]
$$

各项含义：

| 输入 | 含义 | 为什么需要 |
|---|---|---|
| \(s_j\) | patch \(j\) 的 soft semantic distribution | 知道 patch 是 object / water / seabed / background |
| \(H(s_j)\) | 语义熵 | 判断 patch 是否混杂、是否在边界 / 雾化区域 |
| \(r_{ij}\) | query \(i\) 投影到图像后，与 patch \(j\) 中心的距离 | 判断 patch \(j\) 是否可能是 query \(i\) 的图像证据 |
| \(m_{ij}\) | 多视角一致性 | 判断这个证据是否跨视角稳定，鱼这种单视角物体会低 |
| \(\delta_{ij}\) | 深度 / 可见性一致性，可选 | 判断 patch \(j\) 和 query \(i\) 是否可能属于同一表面 |

其中最关键的是 \(r_{ij}\)：

$$
r_{ij}
=
\|\Pi(\mathbf{x}_i)-\mathbf{u}_j\|_2
$$

- \(\mathbf{x}_i\)：第 \(i\) 个 3D anchor / Gaussian；
- \(\Pi(\mathbf{x}_i)\)：把这个 3D 点投影到当前图像；
- \(\mathbf{u}_j\)：第 \(j\) 个 patch 的中心位置。

如果 \(r_{ij}\) 小，说明 patch \(j\) 很可能是 query \(i\) 的图像证据；如果 \(r_{ij}\) 大，就不应该给太高权重。

---

### 3.4 geometry bias 和 medium bias 的区别

geometry branch 要找真实表面证据：

```text
object / coral / rock / seabed / structure patch
```

medium branch 要找水体介质证据：

```text
water / haze / background / low-contrast far region
```

所以两个分支可以输入同样的 \(\phi_{ij}\)，但用不同 MLP：

$$
b_{ij}^{geo}
=
\mathrm{MLP}_{geo}
(
[
s_j,H(s_j),\gamma(r_{ij}),m_{ij},\delta_{ij}
]
)
$$

$$
b_{ij}^{med}
=
\mathrm{MLP}_{med}
(
[
s_j,H(s_j),\gamma(r_{ij}),m_{ij},\delta_{ij}
]
)
$$

这样 MLP 可以学到：

```text
同一个 patch：
对 geometry 分支可能降权；
对 medium 分支可能加权。
```

---

### 3.5 具体例子

假设有两个 3D query：

```text
q1：投影到左侧珊瑚附近
q2：投影到右侧石头附近
```

有一个 patch：

```text
patch j：左侧珊瑚 patch
s_j = [object=0.85, water=0.05, seabed=0.05, bg=0.05]
```

如果只看语义：

```text
patch j 是 object，应该给 geometry 加分。
```

但实际上：

```text
patch j 应该只对 q1 加分，不应该对 q2 加分。
```

因为：

$$
r_{1j}=\|\Pi(\mathbf{x}_1)-\mathbf{u}_j\|_2 \text{ 小}
$$

$$
r_{2j}=\|\Pi(\mathbf{x}_2)-\mathbf{u}_j\|_2 \text{ 大}
$$

所以 MLP 应该输出：

$$
b_{1j}^{geo} \text{ 大}
$$

$$
b_{2j}^{geo} \text{ 小}
$$

这才叫“决定每个 3D query 对哪个 patch 更关注”。

---

### 3.6 attention 输出

geometry 分支：

$$
h_i^{geo}
=
\sum_j
\operatorname{softmax}_j(A_{ij}^{geo})v_j
$$

medium 分支：

$$
h_i^{med}
=
\sum_j
\operatorname{softmax}_j(A_{ij}^{med})v_j
$$

然后：

$$
p_i,\Delta\mathbf{x}_i,\alpha_i,c_i,\Sigma_i
=
\mathrm{MLP}_{geo}(h_i^{geo})
$$

$$
\beta_d(\mathbf{x}_i),\beta_b(\mathbf{x}_i),B_\infty(\mathbf{x}_i)
=
\mathrm{MLP}_{medium}([h_i^{med},\gamma(\mathbf{x}_i)])
$$

## 4. 3D query 从哪里来

如果依赖 SfM / COLMAP 稀疏点云：

$$
\mathbf{x}_i=\text{SfM sparse point}_i
$$

把它投影到多视角图像上采样特征：

$$
f_i
=
\mathrm{Aggregate}
(
F_1(\Pi_1(\mathbf{x}_i)),
F_2(\Pi_2(\mathbf{x}_i)),
\ldots,
F_M(\Pi_M(\mathbf{x}_i))
)
$$

query：

$$
q_i
=
\mathrm{MLP}_q
(
[
\gamma(\mathbf{x}_i),f_i
]
)
$$

这时方法是：

```text
sparse-anchor-based Gaussian refinement
```

不是严格的 generalizable Gaussian generation。

## 5. Occupancy-decoupled sub-voxel Gaussian placement

对第 \(i\) 个 3D anchor：

$$
\Delta\mathbf{x}_i
=
\tanh(\mathrm{MLP}_{pos}(h_i^{geo}))\cdot r
$$

最终 Gaussian 中心：

$$
\mu_i=\mathbf{x}_i+\Delta\mathbf{x}_i
$$

占据概率：

$$
p_i=\sigma(\mathrm{MLP}_{occ}(h_i^{geo}))
$$

最终 opacity：

$$
\alpha_i^{final}
=
p_i\cdot\sigma(\alpha_i)
$$

含义：

```text
p_i 判断这里有没有真实表面；
alpha_i 表示如果有表面，它自身的透明度 / 贡献；
二者解耦可以减少水雾被误建成低 opacity Gaussian。
```

---

## 6. Spatially-varying medium field

普通 view-dependent medium：

$$
\beta_d,\beta_b,B_\infty
=
\mathrm{MLP}(\mathbf{d})
$$

这里只看观察方向，不看空间位置。

本文改成空间变化场：

$$
\beta_d(\mathbf{x}_i),\beta_b(\mathbf{x}_i),B_\infty(\mathbf{x}_i)
=
\mathrm{MLP}_{medium}
(
[
h_i^{med},\gamma(\mathbf{x}_i)
]
)
$$

含义：

```text
每个 3D 位置附近的水体都可以有自己的衰减、散射和背景水色。
```

注意：

```text
spatially-varying medium field 不能单独主打，
因为已有工作也做过类似 medium field。
它要和 semantic-biased evidence routing、occupancy 解耦绑定。
```

---

## 7. Path-integrated medium-aware alpha compositing

普通 3DGS：

$$
C=\sum_iT_i\alpha_i c_i
$$

水下路径衰减：

$$
\mathbf{x}(t)=\mathbf{o}+t\mathbf{d}
$$

$$
A_i
=
\exp
\left(
-\int_0^{d_i}
\beta_d(\mathbf{x}(t))\,dt
\right)
$$

后向散射：

$$
S_i
=
\int_0^{d_i}
B_\infty(\mathbf{x}(t))
\beta_b(\mathbf{x}(t))
\exp
\left(
-\int_0^t
\beta_b(\mathbf{x}(s))\,ds
\right)
\,dt
$$

进入 alpha compositing 前的颜色：

$$
\tilde c_i=c_iA_i+S_i
$$

最终：

$$
C=\sum_iT_i\alpha_i^{final}\tilde c_i
$$

工程近似：

$$
A_i\approx \exp(-\beta_d(\mathbf{x}_i)d_i)
$$

也就是先用 Gaussian 中心点 medium 参数近似整段水路，后续再升级到路径积分。

## 8. 消融实验设计

| 实验 | 设置 | 验证什么 |
|---|---|---|
| A | baseline 3DGS / 原水下 3DGS | 下限 |
| B | + semantic token concat | 证明简单拼语义不如 bias |
| C | + patch-only bias \(b_j\) | 证明只给 patch 全局 bias 不够 |
| D | + pair-wise bias \(b_{ij}\) | 证明 query-patch 关系 bias 有效 |
| E | + geo / med dual bias | 证明物体证据和介质证据分流有效 |
| F | + occupancy-decoupled placement | 验证 floater 和几何指标改善 |
| G | + spatially-varying medium | 验证颜色和远距离区域改善 |
| H | + path-integrated rendering | 验证跨视角颜色一致性改善 |

指标：

| 指标类别 | 具体指标 | 对应模块 |
|---|---|---|
| 渲染质量 | PSNR / SSIM / LPIPS | full model |
| 几何质量 | depth RMSE / Chamfer / F-score | occupancy、sub-voxel offset、pair-wise geo bias |
| 漂浮伪影 | floater count / low-opacity Gaussian ratio | occupancy 解耦 |
| 颜色恢复 | \(\Delta E\)、UIQM、UCIQE | medium field |
| 跨视角一致性 | multi-view color variance | path-integrated rendering |
| 介质可解释性 | attenuation / backscatter map smoothness | medium field |

## 9. 和已有工作的区别

| 已有方向 | 已有方法大概做什么 | 本方法区别 |
|---|---|---|
| semantic-guided underwater 3DGS | 给 Gaussian 加 semantic feature，用 CLIP / SAM 做 semantic consistency loss | 本方法是在参数预测前，用 pair-wise semantic bias 控制 3D query 取证据 |
| TextSplat / semantic fusion GS | text / segmentation / depth / multi-view feature 做动态融合 | 本方法不是多源 feature fusion，而是 \(b_{ij}\) 加到 \(q_i k_j^\top\) 上 |
| underwater medium field | 3DGS + scattering / attenuation field | 本方法 medium field 和 object-medium evidence routing 绑定，不单独主打 medium |
| cost volume / depth Gaussian generation | 用 depth / cost volume 定位 Gaussian center | 本方法不主打 anchor 生成，而主打 sparse anchor 的语义证据路由和水下解耦 refinement |
