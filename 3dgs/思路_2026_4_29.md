# 水下少视角 3DGS 思路整理
# 语义信息怎么加到 ViT 输出 token 里

## 结论

语义信息不是直接替换 ViT token，而是变成一个 **semantic embedding**，再和 ViT 输出的 patch token 融合。

整体流程：

```text
输入图像
→ ViT / DINOv2
→ 得到每个 patch 的视觉 token z_j

输入图像
→ segmentation model
→ 得到像素级语义概率图
→ 对每个 patch 做 average pooling
→ 得到每个 patch 的 soft semantic vector s_j

z_j + s_j
→ MLP / Linear 融合
→ semantic-enhanced token t_j
```

最后送进 cross-attention 的不是原始 ViT token，而是增强后的 token：

$$
t_j = \mathrm{Fuse}(z_j, s_j)
$$

---

## 一个具体例子

假设 ViT 的 patch size 是 \(16 \times 16\)，一张图被切成很多 patch。

第 \(j\) 个 patch 经过 ViT 后得到一个视觉 token：

$$
z_j \in \mathbb{R}^{768}
$$

比如可以理解成：

```text
z_j = [0.12, -0.35, 0.08, ..., 0.44]   # 768 维
```

这个 \(z_j\) 已经包含：

```text
patch 的外观信息
patch 的纹理信息
patch 的上下文信息
ViT 内部位置编码带来的 2D 位置信息
```

所以这里不需要再额外加 2D position embedding。

---

## 语义向量怎么来

假设 segmentation model 输出 4 类：

```text
object / water / seabed / background
```

对第 \(j\) 个 patch 覆盖的 \(16 \times 16\) 个像素，统计每类概率的平均值。

如果这个 patch 里：

```text
object     60%
water      30%
seabed      5%
background  5%
```

那这个 patch 的 soft semantic vector 就是：

$$
s_j = [0.60,\ 0.30,\ 0.05,\ 0.05]
$$

注意：  
这里不要硬写成：

```text
这个 patch = object
```

而是保留 soft distribution：

```text
这个 patch = 60% object + 30% water + 5% seabed + 5% background
```

这样边界 patch、半透明水体、浑浊区域都不会被硬分类。

---

## 语义向量怎么变成 token

原始语义向量只有 4 维，不能直接和 768 维 ViT token 相加。  
所以先过一个小 MLP，把它变成语义 embedding：

$$
e_j^{sem}
=
\mathrm{MLP}_{sem}(s_j)
$$

例如：

$$
s_j \in \mathbb{R}^{4}
$$

经过 MLP：

$$
e_j^{sem} \in \mathbb{R}^{128}
$$

可以理解成：

```text
s_j = [0.60, 0.30, 0.05, 0.05]

MLP_sem(s_j)
→ e_j_sem = [0.21, -0.08, 0.34, ..., 0.17]   # 128 维
```

这个 \(e_j^{sem}\) 就是语义 token / 语义 embedding。

---

## 怎么和 ViT token 融合

### 方式 1：拼接后 Linear，最推荐

把 ViT token 和语义 embedding 拼起来：

$$
[z_j,\ e_j^{sem}]
\in
\mathbb{R}^{768+128}
=
\mathbb{R}^{896}
$$

再用一个 Linear 投回模型维度：

$$
t_j
=
\mathrm{Linear}_{fuse}
(
[z_j,\ e_j^{sem}]
)
$$

输出：

$$
t_j \in \mathbb{R}^{768}
$$

也就是：

```text
ViT token z_j:        768 维
semantic embedding:  128 维
拼接后:              896 维
Linear 融合后:        768 维
```

最后的 \(t_j\) 就是增强后的 image token。

---

### 方式 2：投影到同维度后相加

也可以把语义 embedding 投影到 768 维：

$$
\hat e_j^{sem}
=
\mathrm{Linear}_{sem}(e_j^{sem})
$$

然后：

$$
t_j = z_j + \hat e_j^{sem}
$$

这种方式更简单，但拼接后 Linear 更灵活。

---

## 加完以后怎么用于 Gaussian query

第 \(i\) 个 3D Gaussian query 来自 3D 位置编码：

$$
q_i =
\mathrm{MLP}_q
(
\gamma(\mathbf{x}_i)
)
$$

所有 patch 的增强 token 组成：

$$
T =
\{t_1,t_2,\ldots,t_N\}
$$

然后做 cross-attention：

$$
h_i =
\mathrm{CrossAttn}
(
Q=q_i,\ K=T,\ V=T
)
$$

输出的 \(h_i\) 就是第 \(i\) 个 3D 位置从图像里聚合到的特征。

再用不同 head 预测：

$$
p_i =
\mathrm{MLP}_{occ}(h_i)
$$

$$
\Delta \mathbf{x}_i,\alpha_i,c_i,s_i,r_i
=
\mathrm{MLP}_{gaussian}(h_i)
$$

$$
\beta_d(\mathbf{x}_i),\beta_b(\mathbf{x}_i),B_\infty(\mathbf{x}_i)
=
\mathrm{MLP}_{medium}(h_i)
$$

## 张量形状例子

假设：

```text
batch size B = 2
每张图 patch 数 N = 196
ViT token 维度 D = 768
语义类别数 C = 4
语义 embedding 维度 D_sem = 128
```

ViT 输出：

$$
Z \in \mathbb{R}^{B \times N \times 768}
$$

segmentation patch 语义分布：

$$
S \in \mathbb{R}^{B \times N \times 4}
$$

语义 MLP 后：

$$
E^{sem} \in \mathbb{R}^{B \times N \times 128}
$$

拼接：

$$
[Z,E^{sem}]
\in
\mathbb{R}^{B \times N \times 896}
$$

融合后：

$$
T
=
\mathrm{Linear}_{fuse}([Z,E^{sem}])
\in
\mathbb{R}^{B \times N \times 768}
$$

然后：

```text
T 就是后续 cross-attention 的 K 和 V。
```

## 伪代码

```python
# image: [B, 3, H, W]
# vit_tokens: [B, N, 768]
vit_tokens = vit_encoder(image)

# seg_prob: [B, C, H, W]
# C = 4, classes = object / water / seabed / background
seg_prob = segmentation_model(image)

# 把像素级语义概率池化到 patch 级
# patch_sem: [B, C, H/16, W/16]
patch_sem = avg_pool2d(seg_prob, kernel_size=16, stride=16)

# 展平成 patch token 顺序
# patch_sem: [B, N, C]
patch_sem = flatten_to_tokens(patch_sem)

# 语义向量变成语义 embedding
# sem_embed: [B, N, 128]
sem_embed = mlp_sem(patch_sem)

# 和 ViT token 拼接
# fused_input: [B, N, 896]
fused_input = concat([vit_tokens, sem_embed], dim=-1)

# 融合回 transformer hidden dim
# enhanced_tokens: [B, N, 768]
enhanced_tokens = linear_fuse(fused_input)

# 3D Gaussian query
# gaussian_queries: [B, M, 768]
gaussian_queries = mlp_q(positional_encoding_3d(anchor_xyz))

# cross-attention
# h: [B, M, 768]
h = cross_attention(
    query=gaussian_queries,
    key=enhanced_tokens,
    value=enhanced_tokens,
)

# 输出 Gaussian / occupancy / medium
occ = occ_head(h)
gaussian_attrs = gaussian_head(h)
medium_params = medium_head(h)
```

## 一句话

语义信息的加入方式是：

```text
像素级 segmentation 概率
→ patch 内平均
→ patch-level soft semantic vector
→ MLP 变成 semantic embedding
→ 和 ViT 输出 token 拼接
→ Linear 融合成 semantic-enhanced image token
→ 作为 cross-attention 的 K / V
```

所以不是把语义标签直接塞给 Gaussian，也不是重新做位置编码，而是把每个 patch 的语义分布变成一个可学习 embedding，加到 ViT token 表示里。

## 0. 创新点速查表

| 排名 | 创新点 | 能不能主打 | 一句话说明 | 论文里怎么写 | 区别于已有方法 |
|---|---|---|---|---|---|
| 1 | **语义偏置 cross-attention 证据路由** | **主创新** | 语义不是拼到 token 里，而是变成 bias 加到 \(qk\) attention score 上，直接控制 3D Gaussian query 看哪些 image patch | Semantic-biased evidence routing for sparse-view underwater Gaussian reconstruction | 不同于 SWAGSplatting 给 Gaussian 加 semantic feature / semantic loss；也不同于 TextSplat 做多源 semantic feature fusion |
| 2 | **几何 / 介质双分支 semantic bias** | **主创新** | geometry query 更看 object / seabed / structure；medium query 更看 water / haze / background | Object-medium disentangled semantic bias for Gaussian and medium prediction | 不是统一语义引导，而是按任务把真实表面证据和水体介质证据分流 |
| 3 | **Occupancy-decoupled sub-voxel Gaussian placement** | **主创新之一** | \(p_i\) 判断哪里有真实表面，\(\alpha_i\) 表示透明度，\(\Delta \mathbf{x}_i\) 修正 voxel 内位置 | Occupancy-decoupled sub-voxel Gaussian placement | 不靠 alpha 硬兜底，不是每 voxel 暴力撒 Gaussian，减少水雾被建成 floaters |
| 4 | **Spatially-varying medium field** | **辅助创新，不能单独主打** | 每个空间位置预测 \(\beta_d(\mathbf{x}), \beta_b(\mathbf{x}), B_\infty(\mathbf{x})\)，解释局部水体衰减和散射 | Spatially-varying underwater medium field coupled with semantic evidence routing | 单独做 \(\beta(\mathbf{x})\) 已有相近工作；必须和 semantic bias、occupancy 解耦绑定 |
| 5 | **Path-integrated medium-aware alpha compositing** | **辅助创新 / 强化模块** | 每个 Gaussian 的颜色先经过相机到它之间整段水路修正，再进入 3DGS alpha compositing | Path-integrated medium-aware Gaussian compositing | 比只查 Gaussian 中心点 medium 参数更物理，主要提升跨视角颜色一致性 |

最推荐的贡献排序：

```text
1. Semantic-biased cross-attention evidence routing
2. Object-medium disentangled dual-branch Gaussian prediction
3. Occupancy-decoupled sub-voxel Gaussian placement
4. Spatially-varying medium field with path-integrated rendering
```

不要单独主打：

```text
ViT 提 patch token
语义分割
semantic-guided 3DGS
medium-aware rendering
MLP 预测 Gaussian
triplane / voxel feature generator
```

这些只能作为组件，不是你的核心创新。

## 1. 一句话主线

本文不是简单做：

```text
水下 3DGS + 语义分割 + 水下渲染公式
```

而是针对水下少视角重建中最核心的混淆问题：

```text
真实物体表面证据
水体衰减 / 散射证据
背景雾化证据
少视角导致的不确定几何证据
```

提出一个少视角水下 Gaussian 生成 / 修正框架，让 3D Gaussian query 在预测占据、几何属性和水体介质参数之前，先通过语义偏置的 cross-attention 从多视角图像 token 中选择正确证据。

核心表述：

```text
Semantic-biased evidence routing for sparse-view underwater Gaussian generation.
```

中文意思：

```text
用语义偏置控制 3D Gaussian query 从图像 patch 中取证据，
把真实表面证据和水体介质证据分开，
再分别预测 occupancy、Gaussian 属性和 spatially-varying medium field。
```

术语边界：

```text
如果模型在多场景数据集上训练，测试时输入新场景图像后直接前馈生成 Gaussian，
才可以严格叫 generalizable / 通用 3DGS。

如果主要是在单个水下场景上优化，或者只是把这些模块加入某个场景的训练流程，
就不要叫通用生成框架，应写成 sparse-view underwater Gaussian generation / refinement。
```

## 3. 论文里可以写的核心数学公式

| 序号 | 公式 | 对应模块 | 论文里讲什么 | 建议位置 | 重要性 |
|---|---|---|---|---|---|
| 1 | \(s_j=[p_{obj},p_{water},p_{seabed},p_{bg}]\) | patch-level soft semantics | 每个 patch 不硬分成一个类，而是保留类别概率分布 | Semantic Prior Construction | 必写 |
| 2 | \(H(s_j)=-\sum_c s_{j,c}\log s_{j,c}\) | semantic uncertainty | 混合 patch / 边界 patch 的语义不确定性 | Semantic-biased Attention | 建议写 |
| 3 | \(q_i=\mathrm{MLP}_q(\gamma(\mathbf{x}_i))\) | 3D Gaussian query | 每个 3D anchor 由位置编码生成 query，表示“我要查这个空间位置” | Gaussian Query Initialization | 必写 |
| 4 | \(A_{ij}=q_i k_j^\top/\sqrt{d}+b_{ij}^{sem}\) | semantic-biased cross-attention | 语义 bias 不是拼特征，而是直接加到 attention logits | Semantic-biased Evidence Routing | 必写，主公式 |
| 5 | \(b_{ij}^{geo}=\mathrm{MLP}_{geo}(s_j)-\lambda H(s_j)\) | geometry semantic bias | geometry / occupancy query 更关注真实表面 patch，降低混合不确定 patch | Geometry Evidence Routing | 必写，主公式 |
| 6 | \(b_{ij}^{med}=\mathrm{MLP}_{med}(s_j)\) | medium semantic bias | medium query 根据语义更关注 water / haze / background patch | Medium Evidence Routing | 必写 |
| 7 | \(h_i^{geo}=\sum_j\operatorname{softmax}_j(A_{ij}^{geo})v_j\) | geometry feature aggregation | geometry 分支从图像 token 聚合真实表面证据 | Feature Aggregation | 必写 |
| 8 | \(h_i^{med}=\sum_j\operatorname{softmax}_j(A_{ij}^{med})v_j\) | medium feature aggregation | medium 分支从图像 token 聚合水体介质证据 | Feature Aggregation | 必写 |
| 9 | \(p_i=\sigma(\mathrm{MLP}_{occ}(h_i^{geo}))\) | occupancy head | 用占据概率判断这个 anchor 是否对应真实表面 | Occupancy-decoupled Gaussian Placement | 必写 |
| 10 | \(\Delta \mathbf{x}_i=\tanh(\mathrm{MLP}_{pos}(h_i^{geo}))\cdot v/2\) | sub-voxel offset | Gaussian 中心不锁死在 voxel center，而是在 voxel 内精修 | Sub-voxel Gaussian Placement | 必写 |
| 11 | \(\mu_i=\mathbf{x}_i+\Delta \mathbf{x}_i\) | Gaussian center | 最终 Gaussian 位置由 anchor 加 offset 得到 | Gaussian Parameter Prediction | 必写 |
| 12 | \(\alpha_i^{final}=p_i\cdot\sigma(\alpha_i)\) | occupancy-opacity decoupling | 占据和透明度解耦，减少用 alpha 硬解释水雾 | Occupancy-decoupled Opacity | 必写，主公式 |
| 13 | \((\beta_d(\mathbf{x}_i),\beta_b(\mathbf{x}_i),B_\infty(\mathbf{x}_i))=\mathrm{MLP}_{medium}([h_i^{med},\gamma(\mathbf{x}_i)])\) | spatially-varying medium field | 每个空间位置输出局部水体衰减、散射和背景水色 | Spatially-varying Medium Field | 必写 |
| 14 | \(\mathbf{x}(t)=\mathbf{o}+t\mathbf{d}\) | camera ray | 路径积分里的光线参数化 | Medium-aware Rendering | 建议写 |
| 15 | \(A_i=\exp(-\int_0^{d_i}\beta_d(\mathbf{x}(t))\,dt)\) | direct attenuation | 第 \(i\) 个 Gaussian 的颜色经过相机到它之间整段水路衰减 | Path-integrated Rendering | 必写，主公式 |
| 16 | \(S_i=\int_0^{d_i}B_\infty(\mathbf{x}(t))\beta_b(\mathbf{x}(t))\exp(-\int_0^t\beta_b(\mathbf{x}(s))\,ds)\,dt\) | backscatter | 光路上的后向散射贡献 | Path-integrated Rendering | 建议写，公式较长 |
| 17 | \(\tilde c_i=c_iA_i+S_i\) | underwater Gaussian color | Gaussian 原始颜色变成水下观测颜色 | Medium-aware Alpha Compositing | 必写 |
| 18 | \(C=\sum_i T_i\alpha_i^{final}\tilde c_i\) | final rendering | 最终仍然用 3DGS alpha compositing，只是颜色和 opacity 已被水下模块修正 | Rendering | 必写 |
| 19 | \(L_{occ}=\lambda_{sparse}\sum_i p_i+\lambda_{smooth}\lVert\nabla p\rVert_1\) | occupancy regularization | 防止 occupancy 全 1 或乱噪声，鼓励稀疏和平滑 | Loss Function | 建议写 |
| 20 | \(L_{med}=\lambda_\beta\lVert\nabla\beta\rVert_1+\lambda_{range}L_{range}\) | medium regularization | 防止 \(\beta(\mathbf{x})\) 学成噪声贴图或无物理意义 | Loss Function | 建议写 |

### 3.1 最应该放进主文的公式组合

如果篇幅有限，主文优先放这一组：

```text
1. 3D query:
   q_i = MLP_q(γ(x_i))

2. semantic-biased attention:
   A_ij = q_i k_j^T / sqrt{d} + b_ij^sem

3. dual bias:
   b_ij^geo = MLP_geo(s_j) - λH(s_j)
   b_ij^med = MLP_med(s_j)

4. occupancy-decoupled placement:
   μ_i = x_i + Δx_i
   α_i^final = p_i · σ(α_i)

5. spatial medium:
   β_d(x_i), β_b(x_i), B_∞(x_i) = MLP_medium([h_i^med, γ(x_i)])

6. path-integrated rendering:
   A_i = exp(-∫_0^{d_i} β_d(x(t))dt)
   c̃_i = c_i A_i + S_i
   C = Σ_i T_i α_i^final c̃_i
```

### 3.2 论文公式叙事顺序

方法章节可以按这个顺序写：

```text
先定义 patch semantic distribution s_j
再定义 3D Gaussian query q_i
再写 semantic-biased attention logits A_ij
再分 geometry bias 和 medium bias
然后写两个分支的聚合特征 h_i^geo / h_i^med
接着写 occupancy、offset、Gaussian attributes
最后写 medium field 和 path-integrated rendering
```

这样公式逻辑是连贯的：

```text
语义如何影响取证据
→ 取到的证据如何预测 Gaussian
→ Gaussian 如何和水体介质一起渲染
```

## 4. 最终推荐贡献写法

### 4.1 英文贡献点草稿

```text
We propose a semantic-biased cross-attention mechanism for sparse-view underwater Gaussian generation. Instead of attaching semantic features to Gaussian primitives or simply fusing semantic tokens, patch-level soft semantic distributions are converted into additive attention biases, allowing 3D Gaussian queries to route object-surface evidence and water-medium evidence differently.
```

```text
We design an occupancy-decoupled sub-voxel Gaussian placement module that separates surface existence from material opacity. This reduces medium-induced floating Gaussians and improves geometric localization under sparse underwater observations.
```

```text
We couple Gaussian generation with a spatially-varying underwater medium field and path-integrated medium-aware alpha compositing, enabling the model to explicitly explain attenuation and backscatter along camera-to-surface paths rather than forcing Gaussian color and opacity to absorb water-induced degradation.
```

### 4.2 中文贡献点

```text
1. 提出语义偏置的 cross-attention 证据路由机制。
   语义不是作为输出标签，也不是简单拼到 token 里，
   而是直接作为 attention bias，控制 3D Gaussian query 从哪些图像 patch 取证据。

2. 提出几何 / 介质双分支语义 bias。
   geometry / occupancy query 更关注 object、seabed、structure patch；
   medium query 更关注 water、haze、background patch。

3. 提出 occupancy-decoupled sub-voxel Gaussian placement。
   用 occupancy 判断哪里有真实表面，用 sub-voxel offset 修正位置，
   避免水雾和背景被误建成漂浮 Gaussian。

4. 引入 spatially-varying medium field 和 path-integrated rendering。
   让水体衰减和散射由空间介质场解释，
   不再全部塞进 Gaussian color / opacity / scale。
```

## 5. 整体管线

```text
多视角水下图像 I_1, I_2, ..., I_M
  ↓
ViT / DINOv2 / CNN encoder
  ↓
每张图得到 patch tokens z_j
  ↓
Segmentation model 得到像素级语义概率
  ↓
patch average pooling 得到 soft semantic distribution s_j
  ↓
3D anchors / voxel centers / Gaussian queries q_i
  ↓
semantic-biased cross-attention
  ├─ geometry / occupancy attention: 看真实表面证据
  └─ medium attention: 看水体 / 雾化 / 背景证据
  ↓
每个 3D anchor 得到 h_i^geo 和 h_i^med
  ↓
三个 head
  ├─ Head_occ:      占据概率 p_i
  ├─ Head_attr:     Gaussian 属性 + sub-voxel offset
  └─ Head_medium:   β_d(x_i), β_b(x_i), B_∞(x_i)
  ↓
path-integrated medium-aware 3DGS rendering
  ↓
rendering loss + geometry loss + medium regularization
```

## 6. 语义偏置 cross-attention

### 6.1 为什么不只是拼 semantic token

简单拼接是：

$$
t_j = \mathrm{Linear}([z_j, e_j^{sem}])
$$

这只能告诉模型：

```text
这个 patch 有语义信息，你自己学怎么用。
```

但水下少视角里的问题更具体：

```text
geometry query 不应该被水体雾化 patch 误导；
medium query 反而应该主动看水体 / haze / background patch。
```

所以更强的方式是直接把语义写进 attention score：

$$
A_{ij}
=
\frac{q_i k_j^\top}{\sqrt{d}}
+
b_{ij}^{sem}
$$

其中：

- \(q_i\)：第 \(i\) 个 3D Gaussian query；
- \(k_j\)：第 \(j\) 个 image patch token 的 key；
- \(s_j\)：第 \(j\) 个 patch 的 soft semantic distribution；
- \(b_{ij}^{sem}\)：由语义生成的 additive attention bias。

### 6.2 patch-level soft semantic distribution

假设 segmentation model 输出 4 类：

```text
object / water / seabed / background
```

对第 \(j\) 个 patch 内的像素概率做平均：

$$
s_j =
[p_{obj}, p_{water}, p_{seabed}, p_{bg}]
$$

例如：

$$
s_j=[0.60,0.30,0.05,0.05]
$$

表示：

```text
这个 patch 约 60% 是物体，30% 是水体，5% 是海床，5% 是背景。
```

不要硬投票成单一标签，因为水下边界、雾化、遮挡区域经常是混合 patch。

### 6.3 几何分支 bias

geometry / occupancy query 需要真实表面证据：

```text
object
seabed
structure
清晰边界
```

它应该少看：

```text
pure water
haze
background fog
语义混杂且不确定的 patch
```

公式：

$$
A_{ij}^{geo}
=
\frac{q_i^{geo} k_j^\top}{\sqrt{d}}
+
b_{ij}^{geo}
$$

$$
b_{ij}^{geo}
=
\mathrm{MLP}_{geo}(s_j)
-
\lambda H(s_j)
$$

其中语义不确定性：

$$
H(s_j)
=
-\sum_c s_{j,c}\log s_{j,c}
$$

含义：

```text
如果一个 patch 语义很混，说明它可能在边界 / 水雾 / 遮挡处；
geometry query 对它要谨慎，不要过度相信。
```

### 6.4 介质分支 bias

medium query 需要水体证据：

```text
water
haze
background
远距离低对比区域
```

公式：

$$
A_{ij}^{med}
=
\frac{q_i^{med} k_j^\top}{\sqrt{d}}
+
b_{ij}^{med}
$$

$$
b_{ij}^{med}
=
\mathrm{MLP}_{med}(s_j)
$$

得到：

$$
h_i^{geo}
=
\sum_j
\operatorname{softmax}_j(A_{ij}^{geo})v_j
$$

$$
h_i^{med}
=
\sum_j
\operatorname{softmax}_j(A_{ij}^{med})v_j
$$

再分别预测：

$$
p_i,\Delta \mathbf{x}_i,\alpha_i,c_i,\Sigma_i
=
\mathrm{MLP}_{geo}(h_i^{geo})
$$

$$
\beta_d(\mathbf{x}_i),\beta_b(\mathbf{x}_i),B_\infty(\mathbf{x}_i)
=
\mathrm{MLP}_{medium}(h_i^{med})
$$

### 6.5 一个具体计算例子

假设当前有一个 3D Gaussian query：

```text
q_i：负责判断某个 3D anchor 附近有没有真实物体表面
```

它要从 3 个 image patch 里取证据：

| patch | soft semantic distribution \(s_j=[object, water, seabed, background]\) | 大白话 |
|---|---|---|
| patch 1 | \([0.85, 0.05, 0.05, 0.05]\) | 基本是真实物体 |
| patch 2 | \([0.05, 0.85, 0.05, 0.05]\) | 基本是水体 / 雾 |
| patch 3 | \([0.45, 0.40, 0.10, 0.05]\) | 物体和水体混合，可能是边界 |

#### 6.5.1 没有 semantic bias 时

普通 cross-attention 只看视觉 token 相似度：

$$
a_{ij}
=
\frac{q_i k_j^\top}{\sqrt{d}}
$$

假设算出来：

$$
a_i=[1.2,\ 1.1,\ 1.0]
$$

softmax 后：

$$
\operatorname{softmax}(a_i)
\approx
[0.37,\ 0.33,\ 0.30]
$$

含义：

```text
geometry query 对 object patch、水体 patch、混合 patch 都差不多关注。
```

这在水下很危险，因为水体 patch 可能因为颜色、边缘、纹理相似，被错误当成几何证据。

#### 6.5.2 加 geometry semantic bias 后

对 geometry / occupancy query，希望：

```text
object patch 加分；
water / haze patch 减分；
混合 patch 因为不确定，也适当减分。
```

假设语义 bias 由一个简单规则近似：

$$
b_j^{geo}
=
2p_{obj}
+p_{seabed}
-2p_{water}
-p_{bg}
-0.5H(s_j)
$$

实际论文里这个函数可以由 MLP 学：

$$
b_j^{geo}
=
\mathrm{MLP}_{geo}(s_j)
-\lambda H(s_j)
$$

为了看懂，先用手算近似。假设得到：

$$
b^{geo}=[1.5,\ -1.6,\ -0.2]
$$

加到原来的 attention logits：

$$
A_i^{geo}
=
a_i+b^{geo}
$$

$$
A_i^{geo}
=
[1.2,\ 1.1,\ 1.0]
+
[1.5,\ -1.6,\ -0.2]
$$

$$
A_i^{geo}
=
[2.7,\ -0.5,\ 0.8]
$$

softmax 后：

$$
\operatorname{softmax}(A_i^{geo})
\approx
[0.86,\ 0.04,\ 0.10]
$$

含义：

```text
加 bias 前：
object patch 权重 0.37，water patch 权重 0.33，mixed patch 权重 0.30

加 bias 后：
object patch 权重 0.86，water patch 权重 0.04，mixed patch 权重 0.10
```

也就是说，geometry query 被强制引导到真实物体证据上，水体 / 雾化 patch 不再主导 Gaussian 位置和 occupancy 的预测。

#### 6.5.3 medium query 刚好相反

对于 medium query，希望它多看水体、雾化、背景区域，因为这些 patch 更能反映水体衰减和散射。

假设 medium semantic bias 是：

$$
b_j^{med}
=
2p_{water}
+p_{bg}
-p_{obj}
$$

手算得到：

$$
b^{med}=[-0.75,\ 1.65,\ 0.35]
$$

如果原始 qk logits 还是：

$$
a_i=[1.2,\ 1.1,\ 1.0]
$$

则：

$$
A_i^{med}
=
[1.2,\ 1.1,\ 1.0]
+
[-0.75,\ 1.65,\ 0.35]
$$

$$
A_i^{med}
=
[0.45,\ 2.75,\ 1.35]
$$

softmax 后：

$$
\operatorname{softmax}(A_i^{med})
\approx
[0.08,\ 0.73,\ 0.18]
$$

含义：

```text
medium query 主要看 water / haze patch，
而不是看 object patch。
```

所以同一组图像 patch：

```text
geometry query 看到的是：真实表面证据；
medium query 看到的是：水体介质证据。
```

这就是语义 bias 的核心作用：

```text
不是给 token 多加一点语义信息，
而是在 attention 层面把证据分流。
```

### 6.6 这个模块的创新边界

已有方法容易撞的是：

```text
semantic-guided 3DGS
semantic feature on Gaussian
semantic consistency loss
semantic feature fusion for generalizable GS
```

本方法要强调：

```text
语义不是作为 Gaussian 的附加属性；
语义不是单纯拼到 image token；
语义不是只做 reconstruction loss；

语义是作为 additive attention bias，
直接控制 3D query 在参数预测前从哪些 patch 取证据。
```

## 7. Occupancy-decoupled sub-voxel Gaussian placement

### 7.1 核心想法

不直接：

```text
每 voxel 一个 splat 暴力撒满
```

也不只靠：

```text
alpha 自己决定哪里有东西
```

而是把两个问题拆开：

```text
p_i：这里有没有真实表面？
alpha_i：如果有表面，它有多透明 / 贡献多大？
```

### 7.2 公式

对第 \(i\) 个 3D anchor：

$$
\mathbf{x}_i = \text{voxel center / 3D anchor}
$$

预测 sub-voxel offset：

$$
\Delta \mathbf{x}_i
=
\tanh(\mathrm{MLP}_{pos}(h_i^{geo}))\cdot \frac{v}{2}
$$

最终 Gaussian 中心：

$$
\mu_i = \mathbf{x}_i + \Delta \mathbf{x}_i
$$

占据概率：

$$
p_i = \sigma(\mathrm{MLP}_{occ}(h_i^{geo}))
$$

最终 opacity：

$$
\alpha_i^{final}
=
p_i\cdot \sigma(\alpha_i)
$$

### 7.3 为什么有用

```text
p_i 控制是否存在真实表面；
alpha_i 控制表面本身的透明度 / 渲染贡献；
sub-voxel offset 让 Gaussian 不被锁死在 voxel 中心。
```

对水下少视角的意义：

```text
水雾不应该被建成真实 Gaussian；
背景雾化不应该靠低透明度 Gaussian 硬拟合；
真实表面位置不能被 voxel 分辨率锁死。
```

### 7.4 正则

$$
L_{occ}
=
\lambda_{sparse}\sum_i p_i
+
\lambda_{smooth}\lVert\nabla p\rVert_1
$$

注意：

```text
训练时不要硬剪枝，否则梯度断；
部署时可以 prune 掉 p_i < 0.01 的 Gaussian。
```

## 8. Spatially-varying medium field

### 8.1 模块含义

普通 view-dependent medium：

$$
\beta_d,\beta_b,B_\infty
=
\mathrm{MLP}(\mathbf{d})
$$

等价于：

```text
只看观察方向，不看空间位置。
```

这里改成空间变化场：

$$
\beta_d(\mathbf{x}),\beta_b(\mathbf{x}),B_\infty(\mathbf{x})
=
\mathrm{MLP}_{medium}([h^{med}(\mathbf{x}),\gamma(\mathbf{x})])
$$

含义：

```text
每个 3D 位置附近的水体都可以有自己的衰减、散射和背景水色。
```

### 8.2 为什么必须要它

如果没有 medium field，模型只能把水体造成的颜色变化塞进：

```text
Gaussian color
Gaussian opacity
Gaussian scale
Gaussian position
```

这会导致：

```text
颜色和介质混淆：物体本身颜色 vs 水体衰减分不开；
几何和散射混淆：水雾被当成半透明结构；
跨视角不一致：同一表面换视角后经过不同水路，颜色变化无法解释。
```

所以这个模块不是为了多预测几个参数，而是为了把观测颜色拆成：

$$
\text{observed color}
=
\text{object radiance}
\times
\text{water attenuation}
+
\text{backscatter}
$$

### 8.3 注意创新边界

单独说：

```text
我做 spatially-varying attenuation / backscatter
```

风险比较高，因为已有水下 3DGS / NeRF 工作也在做 medium field 或空间变化介质。

更稳的表述是：

```text
medium field 不是单独主创新，
而是和 semantic-biased evidence routing、occupancy-decoupled placement 绑定：

geometry query 负责真实表面；
medium query 负责水体介质；
两者从 attention 阶段就被语义 bias 分流。
```

## 9. Path-integrated medium-aware alpha compositing

### 9.1 普通 3DGS 合成

假设一个像素对应 3 个 Gaussian：

```text
camera -> G1 -> G2 -> G3
```

深度：

$$
d_1 < d_2 < d_3
$$

普通 3DGS：

$$
C =
T_1\alpha_1c_1
+
T_2\alpha_2c_2
+
T_3\alpha_3c_3
$$

其中：

$$
T_1=1
$$

$$
T_2=1-\alpha_1
$$

$$
T_3=(1-\alpha_1)(1-\alpha_2)
$$

### 9.2 水下路径衰减

第 \(i\) 个 Gaussian 的颜色不是只被当前位置的水影响，而是被相机到它之间整段水路影响：

$$
\mathbf{x}(t)=\mathbf{o}+t\mathbf{d}
$$

直接光衰减：

$$
A_i
=
\exp
\left(
-\int_0^{d_i}
\beta_d(\mathbf{x}(t))\,dt
\right)
$$

后向散射：

$$
S_i
=
\int_0^{d_i}
B_\infty(\mathbf{x}(t))
\beta_b(\mathbf{x}(t))
\exp
\left(
-\int_0^t
\beta_b(\mathbf{x}(s))\,ds
\right)
\,dt
$$

进入 alpha compositing 前的水下颜色：

$$
\tilde c_i
=
c_iA_i+S_i
$$

最终：

$$
C =
T_1\alpha_1\tilde c_1
+
T_2\alpha_2\tilde c_2
+
T_3\alpha_3\tilde c_3
$$

### 9.3 工程近似

严格路径积分贵，可以先做中心点近似：

$$
A_i
\approx
\exp(-\beta_d(\mathbf{x}_i)d_i)
$$

也就是：

```text
先查 Gaussian 中心位置的 medium 参数；
用它近似整段水路衰减；
后面再升级成 path-integrated rendering。
```

论文消融可以比较：

```text
center-query medium
path-integrated medium
```

## 10. 消融实验设计

| 实验 | 设置 | 验证什么 | 预期变化 |
|---|---|---|---|
| A | baseline 3DGS / voxel-to-Gaussian | 不加语义、不加 medium、不解耦 occupancy | 水下颜色和几何都不稳，floaters 多 |
| B | + semantic token concat | 语义只拼到 ViT token 里 | 有小幅提升，但 evidence routing 不明确 |
| C | + single semantic bias | 所有 query 用同一套 \(b^{sem}\) | 比 concat 更强，但几何和介质证据仍可能混 |
| D | + geo / med dual semantic bias | geometry 和 medium 分支用不同 bias | 几何、颜色、跨视角一致性更稳定 |
| E | + occupancy-decoupled placement | 加 \(p_i\)、\(\Delta \mathbf{x}_i\)、\(\alpha_i^{final}=p_i\sigma(\alpha_i)\) | floater 少，depth / Chamfer / F-score 更好 |
| F | + spatially-varying medium | 加 \(\beta_d(\mathbf{x}),\beta_b(\mathbf{x}),B_\infty(\mathbf{x})\) | 颜色恢复、远距离区域、UIQM/UCIQE 更好 |
| G | + path-integrated rendering | 从 center-query 升级到路径积分 | 跨视角颜色一致性、远处 NVS 更好 |
| Full | dual bias + occupancy + medium + path integration | 完整模型 | 综合指标最好 |

### 10.1 指标分组

| 指标类别 | 具体指标 | 主要对应模块 |
|---|---|---|
| 渲染质量 | PSNR / SSIM / LPIPS | full model、medium rendering |
| 颜色恢复 | \(\Delta E\)、RGB angular error、UIQM、UCIQE | medium field、path integration |
| 几何质量 | depth RMSE、AbsRel、Chamfer、F-score | occupancy、sub-voxel offset、geo bias |
| 表面一致性 | normal consistency、edge depth consistency | sub-voxel offset、geo bias |
| 漂浮伪影 | floater count、low-opacity Gaussian ratio、opacity entropy | occupancy-decoupled placement |
| 跨视角一致性 | multi-view color variance、re-render consistency | path-integrated medium、dual semantic bias |
| 介质可解释性 | attenuation map smoothness、backscatter map smoothness | spatially-varying medium |

### 10.2 预期实验故事

```text
semantic token concat 只能带来普通语义增强；
semantic bias 能直接改变 attention 取证据方式；
dual semantic bias 进一步区分真实表面证据和水体介质证据；
occupancy-decoupled placement 主要改善几何和 floater；
medium field 和 path integration 主要改善颜色恢复和跨视角一致性；
full model 证明这不是简单颜色增强，而是几何、外观和介质的联合解耦。
```

## 11. 和已有工作的区别

| 已有方向 | 已有方法大概做什么 | 本方法必须强调的区别 |
|---|---|---|
| semantic-guided underwater 3DGS | 给 Gaussian 加 semantic feature，用 CLIP / SAM 做 semantic consistency loss | 本方法不是给 Gaussian 后验加语义，而是在参数预测前用语义 bias 控制 3D query 取证据 |
| TextSplat / semantic fusion generalizable GS | text / segmentation / depth / multi-view feature 做动态融合，再通过 cost volume 解码 Gaussian | 本方法不是多源 feature weighted fusion，而是 patch-level semantic distribution 直接变成 \(qk\) additive bias |
| WaterSplatting / underwater medium field | 3DGS + volumetric medium / scattering field | 本方法的 medium field 和 semantic evidence routing、occupancy 解耦绑定，不单独主打 medium |
| voxel / triplane -> Gaussian | 从 3D feature field 预测 Gaussian | 本方法要强调 occupancy-decoupled placement 和语义路由，不主打“网络预测 Gaussian” |
| sparse-view depth / cost volume Gaussian generation | 用 plane sweep / cost volume 定位 Gaussian center | 本方法的重点不是 cost volume，而是 3D query 对图像证据的语义分流和水下介质解耦 |

## 12. 工程风险

| 风险 | 原因 | 解决思路 |
|---|---|---|
| semantic segmentation 不准 | 水下偏色、低对比、浑浊导致分割错误 | 使用 soft distribution，不做 hard mask；加入 entropy 作为不确定性 |
| semantic bias 过强 | 可能错杀边界、透明物体、远处低清晰表面 | bias 加缩放系数 \(\lambda\)，从 0 warm up；保留原始 \(qk\) 主导 |
| medium field 不可辨识 | \(\beta\)、颜色、opacity、depth 之间有歧义 | softplus 范围约束、smoothness、先 global 后 spatial warm-up |
| path integration 太贵 | 每个 ray / Gaussian 要多点采样 | 先 center-query，后分段积分；只对 top-k contributing Gaussians 做路径积分 |
| occupancy 塌缩 | \(p_i\) 全 0 或全 1 | 前期固定 \(p=0.5\)，逐步放开；加 sparsity 和 smoothness |
| dense voxel 显存大 | 128^3 特征体成本高 | 先 64^3 验证；再 sparse conv / triplane / hash grid |

## 14. 最终保留的主创新排序

最适合放在论文 contribution 里的顺序：

```text
1. Semantic-biased cross-attention evidence routing
2. Object-medium disentangled dual-branch Gaussian generation
3. Occupancy-decoupled sub-voxel Gaussian placement
4. Spatially-varying medium field with path-integrated rendering
```

不要把以下内容单独当主创新：

```text
ViT 提 patch token
语义分割
semantic-guided 3DGS
medium-aware rendering
triplane / voxel feature generator
MLP 预测 Gaussian
合成数据训练 + 真实数据微调
```

这些可以作为组件，但不能单独撑顶刊创新点。
