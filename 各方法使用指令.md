# 各方法使用指令

本文只记录当前项目里已经有训练/测试入口的方法：

- `3DGS`
- `SeaSplat`
- `SeaThru-NeRF`
- `WaterSplatting`

当前对比实验统一设置：

- 数据集根目录：`src/datasets/SeathruNeRF_dataset`
- 场景：`Curasao`、`IUI3-RedSea`、`JapaneseGradens-RedSea`、`Panama`
- 测试集划分：`--holdout 8 --holdout-offset 0`
- 也就是第 `0, 8, 16, ...` 张作为 test
- 默认训练/测试宽度：`--target-width 720`
- 3DGS/SeaSplat 默认 `factor=1`
- LPIPS：`--lpips-net vgg --lpips-backend official_3dgs`

`3DGS` 和 `SeaSplat` 使用当前 `(sfquant)` 环境。`SeaThru-NeRF` 和 `WaterSplatting` 不要装进 `(sfquant)`，它们各自需要单独环境，并在训练/测试命令里通过 `--python` 指定对应 Python。

## SeaSplat COLMAP undistort 数据准备

SeaSplat 的 COLMAP reader 只接受 `PINHOLE` / `SIMPLE_PINHOLE` 相机。原始 SeaThru-NeRF 数据如果是 `OPENCV` 畸变相机，必须先用 COLMAP `image_undistorter` 生成无畸变 prepared 数据；SeaSplat 训练脚本不会自动做这一步。

- Owner：`scripts/prepare_colmap_undistorted_dataset.py`
- Responsibility：把原始场景的 `images_wb` 和 `sparse/0` 转成 SeaSplat 可直接读取的无畸变 COLMAP 数据。
- Input：`src/datasets/SeathruNeRF_dataset/<scene>/images_wb` 或 `Images_wb`，以及 `src/datasets/SeathruNeRF_dataset/<scene>/sparse/0`
- Output：`outputs/seasplat_prepared/<scene>_undistorted/images` 和 `outputs/seasplat_prepared/<scene>_undistorted/sparse/0`
- Main flow：本地用 COLMAP 生成 prepared 数据，验证相机模型和 split，再打包传到远程服务器。
- Verification：`scripts/inspect_3dgs_protocol.py` 输出相机模型应为 `PINHOLE`，并列出 expected test images。

本地先确认 COLMAP 可用：

```bash
cd /home/leo/Projects/SJTU
source /home/leo/miniconda3/etc/profile.d/conda.sh
conda activate sfquant

command -v colmap
colmap -h | head -5
```

生成缺失场景的无畸变数据：

```bash
cd /home/leo/Projects/SJTU

python scripts/prepare_colmap_undistorted_dataset.py \
  --data-root src/datasets/SeathruNeRF_dataset \
  --out-root outputs/seasplat_prepared_tmp_undistort \
  --scenes IUI3-RedSea JapaneseGradens-RedSea Panama \
  --image-dir images_wb \
  --max-image-size 2000 \
  --overwrite

for scene in IUI3-RedSea JapaneseGradens-RedSea Panama; do
  src="outputs/seasplat_prepared_tmp_undistort/$scene"
  dst="outputs/seasplat_prepared/${scene}_undistorted"
  rm -rf "$dst"
  mv "$src" "$dst"
done

rmdir outputs/seasplat_prepared_tmp_undistort 2>/dev/null || true
```

验证 prepared 数据：

```bash
python scripts/inspect_3dgs_protocol.py \
  outputs/seasplat_prepared/IUI3-RedSea_undistorted \
  outputs/seasplat_prepared/JapaneseGradens-RedSea_undistorted \
  outputs/seasplat_prepared/Panama_undistorted
```

期望看到：

```text
IUI3-RedSea_undistorted             PINHOLE 1383x917
JapaneseGradens-RedSea_undistorted  PINHOLE 1384x918
Panama_undistorted                  PINHOLE 1795x1188
```

传到远程服务器：

```bash

  IUI3-RedSea_undistorted \
```

## SeaThru-NeRF

SeaThru-NeRF 是 NeRF/JAX 方法，不使用 3DGS 的 `sh-degree`、`densify`、`final.ply`。对比时统一的是：

- 同一 scene
- 同一 `--target-width`
- 同一 `--holdout 8 --holdout-offset 0`
- 同一 test metrics

SeaThru-NeRF 需要单独 JAX 环境，当前 3DGS 的 `(sfquant)` 环境一般不够。下面用变量 `SEATHRU_PYTHON` 指向 SeaThru-NeRF 环境里的 Python：

```bash
export SEATHRU_PYTHON=/path/to/seathru_env/bin/python
```

如果只想先生成 resize 后的 prepared data，不启动训练，可以加：

```bash
--prepare-only
```

```bash
python methods/seathru_NeRF/train_seathru_nerf_scene.py \

  --target-width 720 \
  --holdout 8 \
  --holdout-offset 0 \
```
